## 2. DSP (`gen/aliasing.genexpr`) [code]

- gen~ I/O: `in1` MIDI gate (held notes), `in2` Sync impulse, `in3` note-on impulse, `in4` bar
  ramp (`phasor~ 1.0.0 @lock 1`); `out1/out2` stereo. 67 Params (names = the shell's `prepend`
  messages), including the host/MIDI state `playing`, `spb`, `velocity`, `modwheel`.
- Buffers: `atab` (5 × 1024 table) and `aheads` (10 channels × 5 voices of display data, layout in
  the file header). The display script sets a table-valid flag in `aheads` when it restores a
  stored table; gen~ then skips its identity init.
- Per sample: gate and restarts → smoothed pointer pitches (Free: note; Sync: multiplier × note
  value at the tempo + detune) → per voice: LFO 1/2 + Drift → 4 mod slots → pointers (shapes,
  optional PolyBLEP ramp) → write (clip) then read → Drive → Band (4 TPT SVF stages) → Resonator
  → per-voice level and pan → sum → Output → DC blocker → soft clip → safety stage.
- gencheck 9.1.5 + 9.2.0 strict: 0 errors, 0 warnings [measured: tools/check.sh, 2026-11-25].
- Host test (`test/host/run.sh`, export by standalone Max 9.2.1, which compiled the codebox without
  console errors in Max.log): **all 39 checks passed** [measured: 2026-11-25] — silence in MIDI
  mode without a note, audible Drone from the start, DC < 0.01 after the blocker, write frequency
  16004 Hz at the init state, synced write 512 Hz / read 2 Hz at 120 BPM, Pass/Reject band energy,
  stress (every section at its extremes, 48 and 44.1 kHz) finite and bit-identical twice, Write
  Active off keeps the identity table.

## 3. Face (shell `Aliasing.amxd`, generated by `scripts/bootstrap_shell.py`) [code]

- 968 × 169 px, the approved mock-up's layout; parameter table: `python3
  devices/aliasing/scripts/bootstrap_shell.py --list-params` (67 parameters: 64 automatable,
  Page / Display Mode / Table stored only).
- Every control is a real `live.*` parameter with a `jspainterfile`: `aliasing_paint_dial.js`,
  `_tab.js` (pill segments, waveform icons for shape names), `_toggle.js` (pills and the Sync
  button), `_slider.js` (Size bar, bipolar Depth bars), `_menu.js` (mod Source/Target),
  `_number.js` (×1…×64). Accent by scripting name: `w_` / `tone_band_` = write, `r_` / `tone_res_` =
  read, else neutral. Palette Graphite (dark/light picked from `live_control_fg`).
- Pages and modes by scripting-name rules (`js/src/pages_model.ts`, mirrored in
  `scripts/bootstrap_shell.py` for the initial `hidden` flags and in `scripts/check_shell.py`).
- Patch logic: `notein → borax` (notes held → `sig~` → gen~ in1), note-on velocity → `/ 127.` →
  `velocity`, note-on → `click~` → in3; `ctlin 1` → `modwheel`; `plugsync~` → `playing`, `spb`;
  `phasor~ 1.0.0 @lock 1` → in4; Sync button → `sel 1` → `click~` → in2; every parameter →
  `prepend <Param>` → gen~; display gestures → `route …` → the controls; `dict ---atable` ↔ display.

## 4. Display (`js/src/aliasing_display.ts`, `display_model.ts`) [code]

- Table pages: 5 lanes × 24 px, Line (min/max envelope with a soft glow) or 2D (64 cells per
  lane), write head = line + dot (dimmed when Write Active is off), read head = line + ring, header
  with cells / write rate / fs fraction / read rate, Line/2D icons, span overview above the Size
  bar. Tone page: Band + Resonator response (analog prototypes of the GenExpr's SVF stages and
  comb), faint per-voice curves from gen~'s display data, handles as R19.
- Reads `---atab` and `---aheads` at ≤ 30 fps; restores a stored table into the buffer and sets
  the table-valid flag for gen~.

## 6. Test t3 (handover for the next session)

Purpose: first load of v0.2 in Live; does every part run, and how does it look and sound.
Folds in the probe test t2 (painters on 9.1.5, storage). Two rounds: Live with the standalone
Max 9.2.1 (development), then Live with its bundled Max 9.1.5 (release target; painter engine and
dot attributes there are [open]).

1. Safety: limiter after the device, monitor down. The init state is loud-ish (rms ≈ −21 dBFS).
2. Load `devices/aliasing/Aliasing.amxd` on a MIDI track (fresh Set). It sounds at once (Gate =
   Drone). Report: console/MaxPlugLib.log errors, the look (screenshot of each page, dark and
   light theme), CPU.
3. Face: every control paints (no stock-looking control = painter failed); Hz|Sync swaps Pitch ↔
   Rate and Fine ↔ Detune and shows Mult; Page tabs; Size bar hidden on Tone; Res Freq greys out
   with Track Read; automation/modulation dots on a painted dial; map mode (Cmd-M) on a painted
   control; double-click default; typed entry.
4. Sound: Write Pitch around 71 (Fine 0.217) — slow sloped changes; Size small vs large; Write
   Shape Ramp / Tri / Tri ± / =Read; Ramp AA on/off; Tone: Drive, Band (Center/Width/Res, Pass ↔
   Reject by double-click in the curve), FM, Resonator (drag R); Clip.
5. Sync: Write/Read to Sync with transport running/stopped, Mult, Detune, Resync 1 bar; LFO 2 Bar
   retrigger; a mod slot (LFO 1 → Write Pitch, depth 20–50 %); Mod Wheel and Velocity as sources
   (Gate MIDI).
6. Table: draw in a lane with Write Active off (Shift = all, Alt = line, double-click = reset),
   save the Set, reopen: the drawing comes back; Edit → Undo after a drawing.
7. Round 2 (bundled Max 9.1.5): load the same Set; console errors; do the painters draw?
