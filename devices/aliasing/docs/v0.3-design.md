# aliasing — v0.3 design (after test t3)

The user loaded v0.2 in Live 12.4.16 with Max 9.2.1 (test t3, `testlog/aliasing/2026-11-25.md`)
and sent a critique with three screenshots. Three grilling rounds (2026-11-25, user) settled the
v0.3 design below. Presets move to v0.4. Evidence markers as in `CLAUDE.md`; nothing here has run
in Live yet unless marked [measured].

Order of work (D30): this spec → updated mock-up for approval (light and dark) → shell. DSP,
display and painters are built in parallel; the shell (`Aliasing.amxd`) is regenerated only after
the mock-up is approved.

## 1. Decisions

## 2. DSP (`gen/aliasing.genexpr`)

Unchanged core: per voice the read phase `rd` (0..1) is written into the voice's row at the write
position, then read at the read position; core signal `y = 2·val − 1`.

### 2.1 Write shapes (position of the write head, 0..1 of the span)

`p` = write phase (AA-corrected ramp where Ramp AA is on), `s` = Sym + its modulation (−1..1),
`a = (1 + s)/2`.

| # | Shape | Position | Sym |
|---|---|---|---|
| 0 | Ramp | `p ^ 4^(−s)` (s = 0: plain ramp; + bends writes toward the end) | Curve |
| 1 | Tri | skewed triangle 0..1..0, peak at `a` (v0.2) | Skew |
| 2 | Tri ± | `2·Tri − 1`, negative half clipped to cell 0 (v0.2, R22) | Skew |
| 3 | Sine | `0.5 − 0.5·cos(2π·q)`, `q` = phase warped so the peak sits at `a` | Skew |
| 4 | Pulse | 0 while `p < w`, else 1; `w = clamp(a, 0.01, 0.99)` | Width |
| 5 | Pulsar | `p/d` while `p < d`, then **no write** until the cycle ends; `d = clamp(a, 0.02, 1)` | Duty |
| 6 | Spike | up-and-back triangle over `p < d`, then **no write**; `d = clamp(a, 0.02, 1)` | Width |
| 7 | Noise | a new random position at each write-cycle wrap; between two points: stepped (s = −1) … cosine-smooth (s = +1) | Smooth |

The written value stays `rd` for every shape. Clean (D5) replaces the position by `rd`.

### 2.2 Write state and the Write target (D5, D15)

`base = (state ≥ Write)`; `wv = base + Σ depth·source` (Write column); per voice a held flag with
hysteresis: on above 0.52, off below 0.48. A voice writes when the gate is open, the flag is on and
the shape is not resting (Pulsar/Spike). The display's write-enable channel (aheads ch 2) carries
the result per voice.

### 2.3 Mod matrix (D10–D14, D26)

108 Params `mx_<src>_<tgt>` (percent), sources `l1 l2 en dr ve mw vo nb ro`, targets
`wp rp sz sy sp wa dv bc bw rf rb ou`. Per voice and sample: source values (LFOs, Drift and Read Osc
per voice; Env, Velocity, Mod Wheel global; Voice/Neighbour from the previous sample's core
signals), then each target's sum. Depth coefficients are computed once per sample.

### 2.4 Envelope follower (D16, D27)

`e = max(|L|, |R|)` of the sum after the DC blocker (before the limiter); one-pole peak follower
with separate attack/release coefficients; source value `clamp(env · dbtoa(gain), 0, 1)`, used by
the voices in the next sample.

### 2.5 Color limiter (D19, D28)

Stereo-linked, zero latency, after the DC blocker:
1. `x · dbtoa(Gain)`;
2. colour split: one-pole low/high at 700 Hz, tilt gains `gl = dbtoa(−9·Color)`,
   `gh = dbtoa(+9·Color)` (pre-emphasis);
3. saturation `x + S·(tanh(k·x)/tanh(k) − x)`, `k = 1 + 4·S` (S = Saturation 0..1, S = 0 exact
   bypass);
4. de-emphasis (inverse tilt with a second split);
5. peak limiter: target gain `min(1, ceiling/|peak|)`, instant attack, release one-pole
   (`Release`), output never above the ceiling;
6. Off = steps 1–5 bypassed exactly.

### 2.6 Tone switches (D17)

Drive, Band and Resonator mix toward their input with a 5 ms one-pole that snaps to exactly 0/1
when it gets within 1e−5, so "off" is an exact bypass. The filters and the comb keep running while
off (no state jump when switched on).

## 3. Face (mock-up brief and shell constraints)

Frame and areas as v0.2 (968 × 169 px; pointer rows x 8–300, display x 308–636, pages x 644–960)
unless the mock-up changes them.

- **Measured limits in Live** (t3, m4l-boxref): horizontal `live.slider` ≥ 18 px high with stock
  name/number off (with shownumber it grew to ~30 px); `live.numbox` 12–15 px is common;
  2-row `live.tab` ≥ ~31 px; overlapping a `v8ui` hides the other object.
- **Display** 328 px wide, shortened so the 18-px Size slider sits below it inside the 169-px face
  (display about y 6–142, slider about y 145–163); 5 lanes about 22 px each, overview ticks.
- **Write row**: label, Hz|Sync, × N ÷ D fields in Sync, Pitch/Rate, Fine/Detune, Sym (label per
  shape), Shape grid 2 × 4 icons, Freeze | Write | Clean.
- **Read row**: as v0.2 plus × N ÷ D.
- **LFO · Env**: LFO 1 | LFO 2 | Env (Attack, Release, Gain), three columns.
- **Mod**: matrix 9 × 12 with row labels (sources) and short column labels (W Pit, R Pit, Size,
  Sym, Sprd, Write, Drive, Ctr, Wid, R Frq, R Fb, Out); cells about 22 × 12 px.
- **Tone**: Drive, Band, Resonator with power switches in their headers, no underlines.
- **Global**: left Gate, Resync, Sync now, Ramp AA, Transpose; right Limiter (On, Gain, Saturation,
  Color, Release, Ceiling), Width, Output, meter.
- **Panels**: theme-following surfaces behind Write, Read, display and the page area.
