## DSP (`gen/aliasing.genexpr`) [code]

- gen~ I/O: `in1` MIDI gate signal (patch: `notein → borax` "notes active" `→ > 0 → sig~`),
  `in2` sync impulse (`click~`); `out1/out2` stereo. 20 Params (names in the file header);
  the shell sends `<name> <value>` via `prepend`.
- Buffers bound by gen~ attributes: `@atab ---atab` (5 ch × 1024, the table) and
  `@aheads ---aheads` (3 ch × 5: write head, read head, write enable per voice).
- Per voice and sample: LFO phases → pitches (smoothed 15 ms, snapped on restart) → naive phase
  accumulators → shapes → **write** `poke(atab, φr, floor(wpos·1024) wrapped)` → **read** cell
  `floor(rpos·1024)` (or linear between two cells with Smooth) → `2v − 1` → equal-power pan →
  sum · gain (Output dB / 5) · gate envelope → `fixnan → fixdenorm → clip(−1, 1)`.
- Triangle shapes come from a branch-free `skewtri()` (Max 9.1.x fails on user functions with a
  branch inside poke values).

## Deviations from the plan (all under Q1 "inspired by")

| # | Plan | v0.1 | Why |
|---|---|---|---|
| D1 | gate on/off is just the read position (original: read cell 0 when off) | **declick gate envelope** (5 ms one-pole on the gate) on the output | with the gate off every voice reads cell 0 = constant `2·T(0) − 1`, i.e. DC (≈ −10 dBFS on the louder channel at the defaults) into Live; the envelope makes "off" silent and softens on/off steps |
| D2 | MIDI note gates Activate | MIDI gate is **ORed** with the Activate parameter inside gen~; the Activate button does not light up for MIDI | setting a parameter from the patch would flood Live's undo history (`max-patch.md`) |
| D3 | 10 head positions via `snapshot~` (`gui.md` §4) | heads written by gen~ into `buffer~ ---aheads` (3 × 5), read by the v8ui | no 10 `snapshot~`s; the same pattern as Ableton's PitchLoop89 (`buffer~ ---DisplayPositions`) |
| D4 | Sync: write Pitch/Fine := read | the patch copies the Read Pitch/Fine dial values into the Write dials (undoable user gesture), then `click~` restarts both phases; gen~ snaps the smoothed pitches on the restart | |
| D5 | 34 parameters | **24 in v0.1** (21 automatable + Page, Display Mode, Display stored-only): no Tone page controls (v0.2, placeholder text only), no Preset menu (v0.3) | scope |
| D6 | display background follows Live's theme | fixed `#181818`; `bgcolor r g b a` message exists for later wiring to `live.colors` | scope |

## Offline results [measured]

- `tools/check.sh aliasing`: gencheck 9.1.5 + 9.2.0 strict, 0 errors/warnings; TS typecheck,
  13 Node tests, esbuild bundles with handler check; maxdiff parses `Aliasing.amxd` (2026-11-24).
- **gen~ C++ export of a codebox `Buffer`** (Max 9.2.1, unattended `tools/gen-export.sh`): the
  generated `State` has **no member** for `Buffer x("name")`; the code uses an undeclared `x`
  (also with the `buffer~` present, also for a one-line codebox). The host harness declares
  `atab`/`aheads` as float32 globals before including the export. Max itself is not affected
  (the codebox `Buffer` is documented usage) [measured: probe exports 2026-11-24].
- Host test `test/host/run.sh` (2026-11-24), all checks passed:

| Render | Result |
|---|---|
| never activated | exactly silent |
| Activate on, defaults | rms −20.9 dBFS, peak −10.5 dBFS, DC ≈ 0, heads within 0..1 |
| MIDI gate 0.5–2.5 s | silent before, audible during, silent after |
| stress (pitch ±64, all shapes, Symmetry −1, Direction both, Spread 6, LFOs 12/1, Size 0.001, Smooth, Width 2, Output 0, 3 syncs), 48 and 44.1 kHz | finite, peak −5.3 dBFS, table values within 0..1 |
| determinism | two stress renders bit-identical |
| Write Active off | table stays exactly the identity ramp |
| Sync with equal pitches, no spread | table stays within one cell value of identity |

## v0.1b: P1/P2 (2026-11-25) [code]

Redesign R20/R21 applied to the v0.1 shell before the v0.2 rebuild, so a playable fallback exists:

- **Write Pitch −64 … 130** (was ±64) in `gen/aliasing.genexpr` and `Aliasing.amxd` (`wpitch`
  `parameter_mmax` 130, info text names the sample-rate dependence).
- **Init state** in the aliasing regime (own values, not the original's snapshot): Write Pitch 71,
  Fine 0.217 (16004 Hz = fs/3 + 4 Hz at 48 kHz), Write Shape Tri, Symmetry 0, Read Pitch −30,
  Read Fine 0, Read Spread 2.0, Size 0.1; Param defaults in the GenExpr match.
- `scripts/table_sim.py` cases 7–11: at 48 kHz the init state gives long sloped runs with steps
  (the look of the Reaktor recording); at 44.1 kHz the same settings give fine zigzag (the pattern
  is fs-relative, `table-behaviour.md` C4). [code: simulation, 2026-11-25]
- Correction to `table-behaviour.md` C3: v0.1's write Tri is **not** rescaled to 0 … 1; it is the
  −1 … 1 triangle **wrapped into the full row** (negative positions land behind the span, where
  nothing reads). The simulation's "ours" cases modelled a 0 … 1 triangle wrapped in the span.
