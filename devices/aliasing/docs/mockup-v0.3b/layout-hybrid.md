# aliasing — v0.3b face layout: hybrid (`Aliasing.amxd`)

Every presentation rect of the hybrid face as `scripts/bootstrap_shell.py --face hybrid` builds it
(generated by `--list-layout`; regenerate this table whenever a rect changes). Spec: face review
`../face-review-2026-11-25.md` section "Hybrid" (h.1 rects, h.2 compromises), decisions D33–D44 in
`../v0.3-design.md`. Visual target: the mock-ups `build/aliasing/design/hybrid/png/h_*` (local).
Face **918** × 169 px (D47: h.1 was 968). "Visible": `always` = no page rule (pages_model.ts returns null), otherwise the
state at load (page LFO · Env, both pointers in Hz, LFO 2 synced, write shape Tri).

Deviations from h.1 (all measured against the mock-up in the canvas preview, 2026-11-25):
- Comment boxes: text 4 px in from the box edge and the baseline 11 px below the box top (face review
  §0, measured for 8–9 pt; 9.5 pt [hypothesis]), so a label "text at x, baseline b" is the box
  `x − 4, b − 11, w, 15`. "Env Follower" and its hint start 2 px right of h.1 (x 862) to clear the
  divider at x 856.
- Matrix headers are 30 px wide (not 36) so neighbouring headers do not overlap; centred on the cells.
- Fine/Detune use name-row overlays like Sym (h.2 offered either), so the name follows the mode.
- Section switches keep D32's bold title + power symbol at 15 px (D43), not h.2's pills.
- The two version lines are 13 px high (15-px boxes 13 px apart would overlap).
- D46 (user, 2026-11-25): Env Follower bar from the title's "E" to the Gain ring's right edge; Global
  with the version lines on top and Gate / Resync / buttons aligned to y 161; Transpose shown as "Transp".
- D47 (user, 2026-11-25): Write State is a drop-down at 194 y0+20 56 15 with a "State" label in the
  dials' name row; Smooth at the same place in the Read row; the pointer panels are 250 px wide and
  everything right of them sits **50 px further left** than in h.1 (the table below has the final
  rects).
