# aliasing — v0.3b face layout: option (b) (`Aliasing B.amxd`)

Every presentation rect of face B as `scripts/bootstrap_shell.py --face b` builds it (generated by
`--list-layout`; regenerate this table whenever a rect changes). Spec: face review
`../face-review-2026-11-25.md` section "Option (b)" (b.1 structure, b.2 rects, b.3), decisions D33–D44
in `../v0.3-design.md`. Visual target: the mock-ups `build/aliasing/design/b/png/b_*` (local).
Face 800 × 169 px in three bands: display + side page (y 4–93), modulation strip (95–116), constant
dial row (118–168). "Visible": `always` = no page rule, otherwise the state at load (page LFO 1, Mod
Target Write Pitch, both pointers in Hz, LFO 2 synced, write shape Tri).

Deviations from b.2 (all measured against the mock-up in the canvas preview, 2026-11-25):
- Comment boxes: text 4 px in from the box edge, baseline 11 px below the box top (face review §0;
  9.5 pt [hypothesis]); right-aligned labels end 4 px inside their box. The strip's source labels end
  at x 165 + 83·i (b.2: 166) so their boxes stop at the depth box.
- The read pointer has × N ÷ D in Sync like the write pointer (b.2 drew only Write in Sync).
- Section switches are D32's bold title + power symbol at 15 px (D43), not the mock-up's pills.
- Fine/Detune and Sym names are name-row overlays (h.2), as in the hybrid.
- D48/D49 (user, 2026-11-25): Mod menu 80 px (dots on modulated targets), a Clear button at 117 98 30 15,
  so the sources step by 80 px (labels end at x 182 + 80·i, depth boxes at 188 + 80·i).
- The 72 strip cells are `mod_<source>_<target>`; the nine of one source share one rect and the pages
  script shows the one of the Mod Target (pages_model.ts, face b).
